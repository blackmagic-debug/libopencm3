README
======

The libopencm3 project aims to create an open-source firmware library for
various ARM Cortex-M microcontrollers.

This repository is a fork of the original libopencm3 project. It contains specific changes needed for blackmadig-debug.

As Black Magic Debug has migrated to [codeberg](https://codeberg.org/blackmagic-debug/libopencm3), this repository is also now moved and continues to be maintained over there.
